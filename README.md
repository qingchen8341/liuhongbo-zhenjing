# 雅思真经听读 · 离线版（iPhone）

这个文件夹只有程序、图标和开源字体（SIL Open Font License，见 OFL-*.txt），**不含任何词书内容**，可以放在公开网址上。
词库在每台设备上从你自己的 zhenjing-vocab.json 导入一次即可。

## 放到网上（只需做一次，约 5 分钟，用电脑操作）

1. 登录 github.com（没有账号就先免费注册）。
2. 右上角「+」→ New repository，名称填 `zhenjing`，选 **Public**，点 Create repository。
3. 在新页面点 **uploading an existing file**，把这个文件夹里的**全部文件**（不是文件夹本身）拖进去，点 Commit changes。
4. 进入仓库的 Settings → 左侧 Pages → Source 选 **Deploy from a branch**，Branch 选 **main** 和 **/(root)**，点 Save。
5. 等 1–2 分钟，页面顶部会出现网址：`https://你的用户名.github.io/zhenjing/`

## 装到 iPhone

1. 把 zhenjing-vocab.json 存到「文件」App 里（在 Claude 对话中点开文件 → 分享 → 存储到“文件”）。
2. 用 **Safari** 打开上面的网址 → 点分享按钮 → **添加到主屏幕**。
3. **从主屏幕图标打开**（不要在 Safari 标签页里导入：两边的存储是分开的），点「导入词库」，选 zhenjing-vocab.json。
4. 完成。之后断网也能打开、学习、练习、复习。

## 说明

- 第一次从主屏幕打开时需要联网，之后就不需要了。
- 发音用的是 iPhone 自带的声音，离线可用。在 设置 → 辅助功能 → 朗读内容 → 声音 → 英语 里下载 Daniel 或 Serena（增强版）效果更好。
- 阅读文章需要联网生成：在 App 里点「复制提示词」，粘贴到 Claude App 的新对话里，再把回复整段复制回来，点「载入文章」。
- 离线版的进度只存在这台 iPhone 上。要和在线版同步，在「设置 → 在设备和版本之间搬进度」里，一边点「复制进度」，在另一边点「粘贴并合并」。
- 以后有更新，只需把新文件重新上传覆盖，App 联网打开时会自动更新。
